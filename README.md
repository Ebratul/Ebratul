## 🚀 Featured Projects

### 💰 [Setu – AI-Powered SME Finance Copilot](https://github.com/Ebratul/Setu)
Team-built finance copilot with **bilingual RAG answers with citations**, cash-flow forecasting, landed-cost calculations, supplier checks and risk-aware workflows.<br/>
**Tech:** Next.js · TypeScript · FastAPI · LangGraph · PostgreSQL · pgvector<br/>
[![Live Demo](https://img.shields.io/badge/Live_Demo-70A5FD?style=flat-square&logo=vercel&logoColor=white)](https://setu-rouge-omega.vercel.app/) [![GitHub](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Ebratul/Setu)

### 🛠️ [FixedItNow – AI-Integrated Service Marketplace](https://github.com/Ebratul/FixedItNow)
Full-stack marketplace connecting customers with local service professionals: booking, chat, worker verification, reviews, and an **AI assistant that retrieves database-verified professionals**.<br/>
**Tech:** Next.js · TypeScript · NestJS · Prisma · PostgreSQL · FastAPI<br/>
[![Live Demo](https://img.shields.io/badge/Live_Demo-70A5FD?style=flat-square&logo=vercel&logoColor=white)](https://fixeditnowwithragagent-web.vercel.app/) [![GitHub](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Ebratul/FixedItNow)

### 🏭 [METAL-ERP – Enterprise Resource Planning](https://github.com/Ebratul/METAL-ERP)
Frontend modules for factory operations across commercial, production, QC, export, HR, finance and governance.<br/>
**Tech:** Next.js · React · TypeScript · Tailwind CSS · Recharts · Playwright<br/>
[![Live Demo](https://img.shields.io/badge/Live_Demo-70A5FD?style=flat-square&logo=vercel&logoColor=white)](https://metal-erp-ten.vercel.app/dashboard) [![GitHub](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Ebratul/METAL-ERP)

### 🎓 [University Management System](https://github.com/Ebratul/University-Management-System-)
Full-stack academic management app with student and faculty profiles, course registration, attendance, quizzes, fee payments and an admin dashboard.<br/>
**Tech:** Next.js · TypeScript · Tailwind CSS · Prisma · PostgreSQL<br/>
[![Live Demo](https://img.shields.io/badge/Live_Demo-70A5FD?style=flat-square&logo=vercel&logoColor=white)](https://university-management-system-m55d.vercel.app/) [![GitHub](https://img.shields.io/badge/Source-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Ebratul/University-Management-System-)
